HTML

Curso de HTML que ensina, do zero e de forma prática, a criar e estruturar páginas web, abordando tags, mídias, tabelas e formulários.

  • Carga horária: 20 horas
  • Nível: iniciante

CSS

Aprenda a estilizar páginas web, trabalhando com cores, fontes, layouts, responsividade e animações.

  • Carga horária: 20 horas
  • Nível: iniciante

JavaScript

Aprenda a criar interações e funcionalidades dinâmicas para páginas e aplicações web.

  • Carga horária: 30 horas
  • Nível: iniciante

React

Aprenda a desenvolver interfaces web modernas e reutilizáveis utilizando componentes com React.

  • Carga horária: 30 horas
  • Nível: intermediário

Node.js

Aprenda a criar aplicações e APIs no back-end utilizando JavaScript com Node.js.

  • Carga horária: 30 horas
  • Nível: Intermediário

Python

Aprenda os fundamentos da programação com Python, desde a sintaxe até a criação de pequenos projetos.

  • Carga horária: 40 horas
  • Nível: iniciante

Banco de Dados

Aprenda a armazenar, organizar e consultar dados utilizando conceitos de bancos de dados e SQL.

  • Carga horária: 30 horas
  • Nível: iniciante

Git/GitHub

Aprenda a controlar versões de projetos, criar repositórios e colaborar com outros desenvolvedores usando Git e GitHub.

  • Carga horária: 15 horas
  • Nível: iniciante
